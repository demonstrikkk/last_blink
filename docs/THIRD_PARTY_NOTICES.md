# Third-party notices

This file records every third-party work shipped with *The Last Blink: Second Settlement*, the licence it is used under, and the obligation that licence creates. It is generated by hand from `docs/asset_manifest.json` and reviewed against `docs/ASSET_REGISTER.csv`.

**Summary:** all shipped art, audio and font files are **CC0-1.0** or **OFL-1.1**. Nothing shipped requires payment, and no CC-BY attribution obligation is outstanding.

---

## OFL-1.1 — SIL Open Font License 1.1

Licence text: <https://openfontlicense.org/>

The OFL requires that the licence travels with the font, that the font is not sold on its own, and that any Reserved Font Name is not reused by a modified version. Neither font is modified or renamed here, so the obligation is satisfied by keeping `OFL.txt` beside each file.

### 1. Space Grotesk

- **Creator:** Florian Karsten; copyright 2020 The Space Grotesk Project Authors (<https://github.com/floriankarsten/space-grotesk>)
- **Source:** <https://github.com/google/fonts/tree/main/ofl/spacegrotesk>
- **Licence file:** `assets/licenses/LICENSE-SpaceGrotesk-OFL.txt` (also shipped inside `public/assets/fonts/` when fonts are bundled)
- **Used for:** display type, headings, body copy
- **Modifications:** none

### 2. IBM Plex Mono

- **Creator:** IBM / Bold Monday; copyright 2017 IBM Corp. with Reserved Font Name "Plex"
- **Source:** <https://github.com/google/fonts/tree/main/ofl/ibmplexmono>

- **Used for:** machine output, codes, MORROW voice
- **Modifications:** none

**Required attribution string** for the in-game credits screen:
